# AI tool use declaration for the project report

AI-assisted development tools supported research synthesis, code scaffolding, documentation refinement and test generation. The student defined the problem framing, architecture, requirements, Azure deployment choices, safety boundaries, evaluation approach, UI direction and submission scope. The student reviewed implementation changes, analysed failures and retained responsibility for the final system and report claims.

The final implementation was checked through the automated test suite, unattended batch runs, production frontend build, container rehearsal, source inspection and evaluator-facing browser walkthrough. Limitations that still require human evidence are stated in the report rather than presented as completed results.

The project uses standard open-source packages listed in `requirements.txt` and `frontend/package-lock.json`. No third-party source code is intentionally copied into the application beyond those package dependencies. Research references and the capstone-supplied dataset are listed in `Research/` and the report source notes. This declaration should be included in the final PDF report and updated if additional tools or outside code are used.
